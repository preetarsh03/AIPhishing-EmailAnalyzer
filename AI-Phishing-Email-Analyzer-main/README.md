# AI Phishing Email Analyzer

## Overview

AI Phishing Email Analyzer is a Flask-based cybersecurity application that analyzes uploaded `.eml` email files to detect phishing attacks using a rule-based detection engine.

## Features

- Login Page
- Dashboard
- Upload .EML File
- Email Parsing
- URL Extraction
- Rule-Based Phishing Detection
- Risk Score
- Email Analysis Report

## Technology Stack

- Python
- Flask
- HTML5
- Bootstrap 5
- Jinja2
- Regex
- Email Parser
